Judul Project:
Sistem Katalog Produk Toko Kue Menggunakan
Array/List dan Linked List


DESKRIPSI PROJECT
--------------------------------------------------
Project ini merupakan program sederhana untuk
mengelola katalog produk pada sebuah toko kue.

Data produk yang dikelola terdiri dari kode produk,
nama produk, kategori, harga, dan stok.

Program menggunakan Array/List dan Linked List
untuk menyimpan serta mengelola data produk.


BAHASA PEMROGRAMAN
--------------------------------------------------
Python


FITUR PROGRAM
--------------------------------------------------
1. Tambah Produk
2. Tampilkan Produk menggunakan Array/List
3. Tampilkan Produk menggunakan Linked List
4. Ubah Produk
5. Hapus Produk
6. Cari Produk
7. Keluar


STRUKTUR DATA
--------------------------------------------------

Array/List:
Digunakan untuk menyimpan kumpulan data produk
dalam sebuah list.

Node:
Digunakan untuk menyimpan data produk dan
referensi ke Node berikutnya.

Linked List:
Digunakan untuk menghubungkan beberapa Node
yang berisi data produk.

CARA MENJALANKAN PROGRAM
--------------------------------------------------

1. Pastikan Python telah terinstall.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan seluruh file berada dalam satu folder.
4. Buka file main.py.
5. Jalankan file dengan tombol Run.
6. Pilih menu sesuai kebutuhan.
